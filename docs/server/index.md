# 服务器部署的计划与现状(2026.9)

## 计划

为满足日常需求，我将需要用到一台有RAID保护的NAS进行数据的存储与备份，同时使用一台无RAID保护的NAS用于无需备份的数据存储 

外加上一台拥有足够算力的Windows小主机来承载Jellyfin推流的功能，同时Windows也可以用来安装各种网盘软件，承担着下载机的功能 

另外，通过一台瘦客户端原生运行Linux系统，运行部分轻量应用

为了尽可能所有设备在意外断电时的影响，我还需要购买一台UPS来保障断电后的短时间应急供电

UPS将与NUT服务器连接，将UPS的状态同步至所有使用UPS供电的设备 

同时，通过测算机柜温度与群晖内硬盘温度的关系，使用米家自动化来自动调整机柜的散热  

## 现状 

网络方面，我已经实现了内网全千兆网络，且通过局部2.5G网络及链路聚合以提升NAS与其他设备的传输速度。由一台中兴路由器进行拨号上网提供1000/100兆的互联网 

存储方面，现在由一台搭载由4块4TB机械硬盘组成的RAID5存储池的群晖DS923+来提供存储空间 

计算方面，一台装有Windows11的铭凡迷你主机，为Jellyfin的推流提供算力 

同时，增设一台戴尔Wyse3040瘦客户机，运行Debian13，通过Docker提供各项轻量网络服务

电力方面，雷迪司的UPS由于多次异常损坏已经下线。现在已更换为奥兰德UPS，并通过USB与群晖NAS进行连接，由群晖来提供NUT服务器业务 


## 遇到的问题

现在群晖NAS的存储空间日益紧张，然而硬盘价格依然虚高。目前新增全闪NAS的计划仍处于搁置状态。
