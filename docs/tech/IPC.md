
# 我在自行购买以及配置工业IPC时所踩过的坑

## 设计思路

- 我需要使用一个网络摄像头从高处俯瞰一整个房间，以便于在外时实时查看房间的状况

- 外出时，房间内所有设备断电且摄像头附近无插座，因此摄像头需要从机柜取电

- 由于机柜到摄像头距离太长，因此选择PoE模块对摄像头进行供电

- 为防止隐私泄露，需要将供电模块接入米家，并实现回家时断电

- 使用群晖NAS作为NVR，负责录像与监看

## 购物清单

- 工业IPC一台

- 摄像头支架

- PoE模块一个

- 长短网线各一条

- 米家智能插座一个

## 摄像头本体

### 安装过程

!!! Warning
    摄像头与其底座相连接的螺丝及其脆弱，千万不得在调整摄像头角度时按压摄像头

在第一次安装摄像头时，我先将本体与底座通过赠送的螺丝拧紧在一起，放到对应位置再调整俯仰角 

然后，它的螺丝就这样断了……断了……

所以正确的调整方式应当是拧松螺丝，调整角度时尽可能让螺丝少受力，调整好角度再拧紧螺丝

### 关于清晰度的选择

由于我只需要看清房间大致状况，于是购买的时候选择了300万像素的摄像头，若需要具体看清某样细节，可能需要咨询客服 

同时，在购买前还需要与店家沟通好，提出自己的需求，根据店家的推荐来选择镜头、供电方式等选配项目 

## 摄像头支架

初次购买工业摄像头的人在购买时不一定能够记起要一并购买支架<span class="spoiler">（我就是）</span>，工业摄像头在设计上本身并不是为了给家用的，因此安装条件相对家用比较苛刻。  

如果没有提前规划安装位置并测算好参数、准备好打孔工具（抑或是想要免工具安装），很大概率会在将摄像头买回来后发现一个问题：“我要怎么把摄像头固定好？”

这个时候很大概率就需要借助摄像头支架了。 

购买摄像头支架没什么要点，只需要测量好安装位置以及将摄像头底座螺丝孔的孔位信息发送给售卖支架的客服，让客服推荐合适的即可。 

在固定方面，如果希望免工具安装，那基本上就需要准备一管免钉胶<span class="spoiler">一切免工具安装的神</span>，商家自配的纳米胶质量通常不是很好，容易脱落 

## PoE供电模块

!!! Warning
    在购买供电模块时，一定要提前向商家问清楚是否为标准PoE供电模块。

网店在售的一些供电模块为网桥专用的非标PoE模块，在购买前最好问清楚客服，最好还能给出摄像头的PoE供电参数让客服能够判断你所购买的这一款供电模块是否能正常为摄像头供电。 

我在第一次购买PoE供电模块时，便不小心买到一个普联的非标PoE供电模块，好在并没有烧坏摄像头。
